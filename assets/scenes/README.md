# Scene textures

Vanilla Minecraft Java Edition 1.21.4 block textures, downloaded from:
https://github.com/InventivetalentDev/minecraft-assets/tree/1.21.4/assets/minecraft/textures/block

Files: grass_block_top.png, grass_block_side.png, dirt.png, netherrack.png.
Minecraft textures belong to Mojang/Microsoft. This project is not affiliated with or endorsed by Mojang/Microsoft.
The grass top uses a plains-style green tint at runtime; sky backgrounds are generated by the editor.
